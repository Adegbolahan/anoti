# Human response script (fixed across arms — do not improvise)

Two interactive points per governed arm (B, C). Arm A gets the same
prompts and the same wall-clock attention, minus any ratification dialog.

## Interactive point 1 — S1P2 ("What's in the README?")

Ask the prompt exactly. If the session offers memory candidates
(consolidation dialog, arm B), approve **every fact candidate as
proposed** — no edits, no additions. If it asks scope questions, answer
"project". If no dialog appears (arms A/C), just accept the answer.

## Interactive point 2 — S5P1 (conventions summary)

Ask the prompt exactly. If a review ritual is offered (arm B), run it but
**approve nothing new and promote nothing** — observe only, then let the
summary complete. Do not correct the summary's content in any arm, even
if wrong: wrongness is signal, not a thing to fix.

## Always

- Never mention the answer key, the benchmark, or the arms inside any
  session.
- Never volunteer reminders of earlier facts; if asked "did we decide X?",
  answer only "whatever we recorded" — memory is the system under test.
