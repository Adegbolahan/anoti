# High-Level Stories

<!-- Human-owned. What "good" means for anoti, in human terms. Agents

- As a developer starting a session, I need established knowledge already
  in context, so I never re-derive or contradict what we agreed.
  Done means: the digest arrives unasked.
- As a developer making a trivial request, I need zero methodology
  overhead. Done means: no visible ritual on small asks.
- As the human owner, I need everything entering shared memory to pass
  through my ratification. Done means: no approved record without my
  decision recorded as an event.
- As a developer mid-task, I need work traced to goals and values.
  Done means: frames cite roadmap and story refs; untraceable work stops.
- As the human owner, I need destructive or outward actions gated by
  judgment. Done means: matched actions ask; absence never authorizes.
- As a future session or different agent, I need memory to be trustworthy
  data. Done means: validated, provenance-checked, injected as
  reference-never-instructions.
- As the project owner, I need claims to carry evidence and survive
  challenge. Done means: status moves only on cited evidence; demotion as
  legitimate as promotion.
- As a maintainer, I need methodology failures to become fixes.
  Done means: retrospectives file lessons; recurring lessons become
  skills.
