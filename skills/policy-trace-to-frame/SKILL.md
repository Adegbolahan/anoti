# Policy: trace-to-frame

**Applies:** always — universal; every role carries this policy.

**Procedure:**

1. Before acting, name which element of the attention frame (goal, scope,
   success criterion, or assigned unknown) the action serves.
2. Work that serves no frame element is out of scope: stop, and report the
   mismatch to the main session instead of doing it. Scope grows by
   re-framing, never by drift.
3. If the frame itself seems wrong (goal stale, scope impossible), say so
   as a labeled judgment in your report — do not silently substitute your
   own frame.

**Binds:** the attend skill (frame producer), the inhibition hook (its
"does this trace to the frame?" check reads the same frame).

**Violation handling:** untraceable work is discarded, not merged; repeated
drift is a report-level finding.
